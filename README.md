# Mental Wellness Hub

An interactive frontend web application designed as an educational and check-in portal for mental wellness. Built as a student project during Year 1 Semester 1 at Singapore Polytechnic for the Front-End Development (FED) module.

## 🌟 Features
* **Home Portal**: Clean navigation, responsive layouts, and modern hero grid structures.
* **Mindfulness Resources**: Interactive tips, strategies, and resources for stress management.
* **Mental Health Check-In Form**: A client-side validated form that gathers mood data and user reflections, providing immediate interactive feedback.

## 🛠️ Technologies
* HTML5 (Semantic Structure)
* CSS3 (Custom Styling)
* Bootstrap 5 (Responsive Layout Grids)
* JavaScript (Form Validation and Dynamic Elements)
